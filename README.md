# TP-MS-Ecom

Projet pédagogique réalisé dans le cadre de l’apprentissage par projet de la formation **J2EE avancé et Spring Boot**, destinée aux étudiants de **5e année d’ingénierie en développement à l’EMSI**, enseignée par **M. KHALIL Salim**.

Le projet représente une application e-commerce composée de trois microservices : gestion des clients, catalogue de produits et gestion des commandes.

Il sert de base aux travaux pratiques sur l’infrastructure Spring Cloud, les communications synchrones avec OpenFeign et GraphQL, la résilience et les communications asynchrones avec RabbitMQ et Kafka.

La version initiale utilise Java 17, Spring Boot, Maven et des bases H2 en mémoire alimentées automatiquement au démarrage.
